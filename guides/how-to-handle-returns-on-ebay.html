How to Handle Returns on eBay as a Reseller

Every reseller gets returns eventually. A buyer changes their mind, a size runs small, or something got damaged in the mail. One return won't sink you, but if you don't plan for them they quietly eat into the profit you thought you made. This guide covers how to set your policy, handle a return calmly, and count returns in your numbers.

eBay's return rules, protections and fee policies change. This guide explains how the pieces generally work; always check eBay's current seller help pages and the details on each return request.

1. Pick a return policy on purpose

When you list, eBay lets you choose whether you accept returns, how long the buyer has, and who pays return shipping. The usual choices for small sellers:

  • No returns. Buyers can't return an item just because they changed their mind. This does not protect you if the item isn't as described or arrives damaged; eBay's buyer protection still covers those cases.
  • 30-day returns, buyer pays return shipping. A common middle ground. Some buyers feel safer bidding or buying, and a change-of-mind return costs you less.
  • 30 or 60-day free returns (you pay return shipping). Can make listings more attractive to buyers, but every return costs you a label. Usually makes more sense on higher-priced items than on $15 flips.

There is no single right answer. Many resellers accept returns on clothing and shoes, where fit is the main worry, and keep tighter policies on low-priced items where a return label would cost more than the profit.

2. "Changed my mind" vs "not as described"

These two kinds of returns work differently, and knowing which one you're dealing with keeps you calm:

  • Remorse returns (didn't fit, didn't like it, found it cheaper) follow your return policy. If you said no returns, you can politely decline. If you accept returns with buyer-paid shipping, the buyer pays the label.
  • "Not as described" or damaged returns are covered by eBay's buyer protection no matter what your policy says. In these cases the seller usually ends up paying return shipping.

Sometimes a buyer picks "not as described" for what is really a change of mind, because it gets them a free label. If the listing clearly showed the item and its flaws, respond politely, stick to facts, and use eBay's return tools and support rather than arguing in messages.

3. Prevent returns in the listing

Most avoidable returns come from a buyer expecting something different from what arrived. The listing is your best defense:

  • Show every flaw in photos, close up, and mention it in the description. See how to take eBay listing photos that sell.
  • Give measurements for clothing and shoes (pit to pit, length, inseam, insole), not just the tag size.
  • Say exactly what's included: cables, manuals, remote, box, accessories. If it's not pictured, say whether it's included.
  • Say how you tested it. "Powers on and plays discs" is better than "works great."
  • Use accurate condition and item specifics. A clear title helps too; see how to write eBay listing titles that get found.
  • Pack well so it arrives the way it left. See how to ship items cheaply on eBay.

4. When a return request comes in

  1. Read the reason and any photos the buyer sent before replying.
  2. Respond inside eBay's return tools and within the time eBay gives you. Letting a request sit can let the buyer escalate it.
  3. Consider your options. Depending on the case, you may accept the return, offer a partial refund so the buyer keeps the item, or, for a cheap item, refund without asking for it back when the return label would cost more than the item is worth.
  4. Stay polite and factual. Short, friendly messages keep things simple and look better if eBay ever reviews the case.

Example (made-up numbers for illustration only): a buyer says a $14 shirt doesn't fit. A return label would run about $5, and the shirt may come back wrinkled or not at all. Offering a partial refund or simply refunding and letting them keep it might cost you less time and money than processing the return. On a $90 jacket, the same math points the other way: getting it back and relisting it is clearly worth a label.

5. Inspect what comes back

  • Check it as soon as it arrives: same item (match a mark, tag or serial number you noted), same condition, all parts included.
  • Photograph it on arrival, especially if something is wrong.
  • If it came back damaged, used or swapped, don't just eat it. eBay's return process has ways to report this and in some cases issue less than a full refund; check the current rules on the return request.
  • Refund promptly when it checks out, so the case closes cleanly.

6. Relist fast

A returned item is inventory again. If it's in sellable condition, relist it the same day while your photos and description are still ready. Update the listing if the return taught you something, such as adding measurements or a clearer photo of a flaw. If you track days to sell, note that the clock restarts; see how to calculate sell-through rate.

7. Count returns in your real profit

Returns cost more than the refund. The outbound label you paid usually isn't given back, the return label may be on you, and the item sits unsold again. Some fees may be credited back on a full refund, but don't assume all of them are; check your eBay payouts and fee details for each return.

Example (made-up numbers for illustration only): you sold a pair of boots for $45 and paid $11 to ship them. The buyer returns them as "not as described," so you pay a $12 return label and refund the $45. Even if some fees come back, you're out about $23 in shipping before you sell them again, which is profit the next sale has to make up.

Keep a simple note of returns in your inventory sheet: date, reason, shipping lost, and whether it relisted. After a few months you'll see which categories or sizes come back most, and you can adjust your policy or buy fewer of them. Common return mistakes

  • Thinking "no returns" means no returns, when "not as described" claims are still covered.
  • Hiding or skipping flaws in photos and description.
  • Arguing with the buyer instead of using eBay's return tools.
  • Missing response deadlines on a return request.
  • Refunding before inspecting what came back.
  • Letting returned items sit in a box instead of relisting.
  • Not counting lost shipping when you add up profit.
